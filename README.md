# Robotics

A robotics simulator for building, programming, and testing virtual robots with Blockly and Python.

**Try it in your browser, no account needed:** [mytekdev.com/tools/robotics](https://mytekdev.com/tools/robotics). The page has a live demo and explains what students learn from it.

Based on [GearsBot](https://github.com/QuirkyCort/gears) by [QuirkyCort](https://github.com/QuirkyCort).
